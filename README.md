# Cosmopings website

A responsive, static landing page for the Cosmopings Discord bot.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive styling and visual design
- `script.js` — small progressive enhancement

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a separate public repository, for example `cosmopings-website`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your default branch (usually `main`) and `/ (root)`, then Save.
6. Wait for the deployment and open the URL shown in the Pages settings.

GitHub Pages serves static HTML, CSS, and JavaScript. It does not run the Discord bot or any server-side Python code.

## Before launch
Replace or add real links for:
- Discord bot invite
- Support server
- Documentation
- Source code

Do not publish bot tokens, API keys, or other secrets in this repository.
