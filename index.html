What does Cosmopings do?

Cosmopings watches a configured YouTube channel for new covers and livestreams, detects the content type, and sends updates to dedicated Discord channels.

Does the status panel show the real bot status?

Yes. It checks the bot host's public status API. If the host cannot be reached, the panel reports the connection as unavailable instead of claiming the bot is online.

Does this website host the Discord bot?

No. GitHub Pages hosts this website. The bot runs separately on its hosting service, and this page reads its public status endpoint.

Can I customize my own Cosmopings?

Yes. The bot source is public, so you can explore the code, fork the repository, and adapt it for your own server and YouTube channel.

How are covers and livestreams separated?

Cosmopings uses configured keywords, hashtags, and YouTube live-broadcast information to classify content before sending a notification.

Where can I report an issue or get in touch?

Contact the project owner on Discord: palmtree_panik.
